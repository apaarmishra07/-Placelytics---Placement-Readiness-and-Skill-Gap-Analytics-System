You are a Senior Full Stack Developer + System Architect. Build and explain a complete full-stack web app:

Project: Placelytics – Placement Readiness & Skill Gap Analytics System

Goal:
Web app to evaluate student placement readiness, calculate score (0–100), identify skill gaps, show dashboards, use Redis caching for performance, and generate PDF reports. Replaces manual Excel tracking.

⚙️ Tech Stack

Frontend: React, Bootstrap, Chart.js (react-chartjs-2), Axios, React Router
Backend: Flask (Python)
Database: PostgreSQL
Cache: Redis (TTL-based)
PDF: ReportLab

🧠 Core Logic

Score = (Marks×0.4) + (Aptitude×0.2) + (Skill×0.3) + (Projects×0.1)
Range: 0–100

🔴 Redis

Key: student_score_<id>, TTL: 600s
Flow: Check Redis → if hit return → else fetch DB → calculate → cache → return
On update: delete key (cache invalidation)

🏗 Architecture

User → React Frontend → Flask API → PostgreSQL → Redis (cache)
